# Рынок труда дата-аналитиков: итоговый проект

Итоговый групповой проект по программе «Аналитика данных» (data-diving, 2024).
Мы изучили спрос на аналитиков данных и факторы, которые влияют на зарплату.

📄 Презентация: [`Итоговое_задание_аналитика.pptx`](./Итоговое_задание_аналитика.pptx)

## О проекте

- **Цель:** выявить региональную и отраслевую специфику рынка труда дата-аналитиков.
- **Данные:** структурированная выгрузка вакансий из РосНавык, февраль–май 2024.
- **Задачи:** собрать данные, проанализировать требования к навыкам и опыту, оценить зарплаты и динамику спроса по месяцам, создать интерактивный дашборд.

## Инструменты

SQL (DBeaver) · Python (pandas, Jupyter Notebook) · Power BI

## Что выяснили

- Спрос и медианные зарплаты выше в Москве и Санкт-Петербурге.
- Самые высокие медианы у системных аналитиков и дата-сайентистов.
- Зарплата сильнее всего растёт в первые 6 лет опыта.
- Знание английского не определяющий фактор: медианы близки.
- График работы и вид трудоустройства напрямую влияют на зарплату.
